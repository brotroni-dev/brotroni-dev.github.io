# Assets — where each file goes

Drop your exported images and videos into the matching folder, then write the
filename into the relevant content template in `../content/`.

| Folder | What goes here |
|---|---|
| `home/` | The 3 homepage card images (one per case study) |
| `about/` | An optional photo of you (later — none needed for now) |
| `case-studies/multi-room-scan/` | Hero, research board, wireframes, final screens, GIFs/video for Case Study 1 |
| `case-studies/desktop-3d-floor-plans/` | Same set of visuals for Case Study 2 |
| `case-studies/ar-experience/` | Same set of visuals for Case Study 3 (mostly video/GIF) |

## Naming
Lowercase, hyphens, numbered sequences:
`hero.mp4`, `research-board-01.jpg`, `wireframe-01.jpg`, `solution-01.jpg`, `demo-01.mp4`

## Formats
- Screens / photos → `.jpg` (or `.png` if transparent), ~2000px wide max
- Animations → `.mp4` preferred, or `.gif`
- Video demos → `.mp4`
